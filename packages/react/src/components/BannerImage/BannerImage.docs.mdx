## Usage

Pass a `BannerImage` to the `image` prop of `Modal` (with `imageSize="lg"`), or
place it before `CardBannerContent` in a `Card`.

```tsx
<BannerImage width="160px" height="174px">
  <img src={banner} style={{ width: '100%', height: '100%', objectFit: 'cover' }} alt="" />
</BannerImage>
```
